اليوم 20 - HTTP Request لأي API بدون node جاهز: بدون كود ولا بالكود؟

كيف يشتغل:
- 4 مدن فلسطينية: غزة ورام الله ونابلس والخليل
- node اسمه HTTP Request يكلم خدمة طقس مجانية (Open-Meteo) بدون أي مفتاح تسجيل
- كل اللي بتكتبه: رابط الخدمة، وإحداثيات المدينة
- الطريقة الأولى بدون كود: تختار الحقول الجاهزة من الرد: درجة الحرارة، سرعة الرياح، ورمز الطقس
- الطريقة الثانية بالكود: سكربت يحول الأرقام الخام لجواب مفهوم بالعربي
- الكود يحسب أعلى وأدنى حرارة، واحتمال المطر، وأفضل ساعة للخروج من 24 قراءة بالساعة
- يعطيك نصيحة جاهزة: خذ مظلة، أو تجنب الظهيرة، أو البس جاكيت
- تقرير مقارنة جاهز بين الطريقتين لكل مدينة

النتيجة:
- الاتصال بالخدمة نفسها ما احتاج ولا سطر كود
- بدون كود: 4 حقول لكل مدينة، والطقس طلع رقم خام (مثلاً رمز 3)
- بالكود: 8 حقول لكل مدينة، والطقس طلع "غائم" بالعربي مع نصيحة وأفضل ساعة للخروج

القاعدة اللي طلعت فيها:
- بدك تربط أي خدمة وتاخد حقول جاهزة من ردها؟ استخدم HTTP Request بدون كود
- الرد فيه مصفوفات أو رموز تحتاج حساب أو ترجمة لنص؟ استخدم الكود بعد الاتصال

القالب الجاهز في أول تعليق، مع خطوات الاستيراد.

باقي 10 أيام من السلسلة.

سؤال لك: أي خدمة أو تطبيق بتتمنى تربطه بشغلك وما لقيت له ربط جاهز؟
